# Code of Conduct

## The short version

Be decent. Assume the other person is doing their best.

## The longer version

This project follows the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short:

- **Be respectful.** Disagreement about the code is fine. Disagreement
  about the person is not.
- **Assume good faith.** A question is not an accusation, and a
  review comment is about the change, not about you.
- **Accept feedback gracefully.** Especially the kind that points out
  your measurement is wrong. That is the most valuable feedback there
  is, and this project is built on it.
- **Do not harass anyone**, publicly or privately.

Maintainers are responsible for clarifying the standards of acceptable
behaviour and are expected to take appropriate and fair corrective
action in response to any instance of unacceptable behaviour.

## Reporting

Report a problem to the maintainer by opening an issue, or by email to
pat@patpadgett.com if the issue is about the maintainer. All reports
will be reviewed and investigated, and the privacy and security of the
reporter will be respected.

## Scope

This applies in the project's spaces - the repository, the issues, the
discussions - and when an individual is representing the project in
public spaces.
